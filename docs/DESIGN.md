# Дизайн: «Небо і золото»

## Теза

Бренд заданий власником 03.10.2026: логотип — золоті зрізані літери PBT на блакитному градієнті неба. Отже сайт світлий і енергійний:
небо (#1A87F5→#339DFD→#76CAFC→#AAE4FC) як ґрунт і глибокі секції, золото (#F8E901→#FDC501→#F97316) — лише дія, ціна й акцент,
чорнило #062B5C — текст на світлому. Жодного тексту золотом на білому (1.6:1); золото як текст — лише на глибокому синьому (≥7:1).

Предмет лишається тим самим: найдорожча послуга за 1С — амфібія, найпопулярніше відео — амфібія. Тому герой — монтаж власних кадрів
клієнта (16 с, шість фрагментів), а не стокове відео.

## Симетрія

Усі заголовки секцій центровані (eyebrow з двома золотими рисками, h2 у два рядки, lead ≤66ch). Сітки парні: роботи 5/2/1, парк 4/3/2/1
(телефон — компактний рядок), матеріали 4/2/1, доказ 3/2/1. Одна ширина контенту 1360 px. Картки однакової висоти всередині ряду.

## Рух (усе вимикається `prefers-reduced-motion` і `data-quality=static`)

| Де | Що | Механізм |
|---|---|---|
| Герой | відео-монтаж (wide/tall за профілем), літери ПБТ піднімаються й мерехтять золотом, слова заголовка з'являються по одному, промені, золоті блиски на canvas, лічильники, вода затоплює герой при скролі, відео масштабується 1→1.14 | CSS keyframes + функція прогресу скролу |
| Навігація | золота смуга прогресу, скло при скролі, ховається на скролі вниз | scroll |
| Секції | поява зі стаггером `.rv` (opacity+translate, затримка `--d`) | IntersectionObserver |
| Роботи | відео-петлі грають, коли картка в кадрі; підйом картки на наведенні | IntersectionObserver + hover |
| Масштаб | липка кіно-сцена 100svh, шість розділів прокручуються поверх; два шари відео перехрещуються 1,1 с із повільним наближенням 1.08→1; слово розділу — золотий градієнт Tektur; рейка розділів праворуч; телефон — портретний кроп 9:16; спокій/бандл — сітка постерів | IO (-45% поле) + CSS transitions |
| Парк | 3D-нахил картки за вказівником, зум фото, фільтр чипами з повторною появою | pointermove |
| Ціна | золотий повзунок із заповненням, сума «перераховується» твіном 520 мс | rAF |
| Доказ | 6 відео-петель у кадрі, лічильники фактів, нескінченна стрічка логотипів | IO + CSS marquee |
| Карта | маршрути з Полтави малюються (stroke-dashoffset), маяк пульсує, області світяться на наведенні | SVG + IO |
| Заявка | золота галочка малюється після прийому | SVG stroke |
| Усюди | золоте світло за курсором (лише точний вказівник), хвильові роздільники секцій, блиск кнопок | CSS |

## Профіль пристрою

`wide-fine / medium-hybrid / compact-touch` за можливостями. На телефоні герой бере портретний монтаж `hero-tall`, картки парку — компактні рядки,
курсорного світла й нахилу карток немає.

## Типографіка

Tektur (змінний, зрізані кути — найближчий до літер лого шрифт із кирилицею) — заголовки, числа, чипи; IBM Plex Sans — текст; IBM Plex Mono — підписи й цифри в таблицях (спільний із CRM).

## Колір відео

Один look для всієї зйомки — `config/pbt-look.cube` (33³), генерується формулами `tools/lut.py`: S-крива навколо середнього сірого
(нахил 1,175), розщеплене тонування тіні→чорнило #062B5C / світла→золото #FDC501 у хромі, вібранс, підсилення неба до sky-700
і жовтої фарби техніки до золота, м'який відкат світлих вище 0,88, підняті чорні з синім відтінком. Тест: сіра вісь монотонна,
файл відтворюється байт-у-байт.
