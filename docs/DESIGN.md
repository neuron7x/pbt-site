# Дизайн: «Занурення»

## Теза

Найдорожча послуга ПБТ за даними 1С — оренда екскаватора-амфібії (1,5 млн грн за три акти; більше, ніж будь-яка окрема машина).
Найпопулярніше відео в TikTok клієнта — теж амфібія (2 995 переглядів проти медіани ~650). Отже предмет сайту — **техніка, що працює у воді**,
а не «оренда спецтехніки за низькими цінами». Звідси колір (вода, небо, лід), метафора (сторінка — занурення від поверхні до дна)
і сигнатура (рейка прогресу — глибиномір у метрах).

## Чим відрізняється від ЛЮБЕ АВТО (той самий метод, інший предмет)

| | ЛЮБЕ АВТО / ВОДНИК | ПБТ |
|---|---|---|
| Світ | асфальт, крейда, стоп-сигнал | ніч над водою, сталь, небо |
| Герой | авто під'їжджає на камеру (кадри авто) | амфібія працює у воді (власні кадри клієнта), сторінка тоне в синє |
| Рейка | дорожня розмітка з авто | глибиномір з поплавком, 0 → −6 м |
| Шрифт заголовків | Unbounded (широкий) | Sofia Sans Extra Condensed 900 (трафарет на борту машини) |
| Цифри | Geologica | IBM Plex Mono — спільний із CRM «ПБТ-Спецтехніка» |
| Калькулятор | економіка авто до номерів | зміна: години × ставка + подача тралом за км (трал за вагою машини) |

## Токени

```
--night #03101F  ґрунт          --deep #07213D  глибина        --steel #0E3A62  сталь
--blue  #1769B5  вода           --sky  #4FB2FF  небо / дія     --ice   #BFE3FF  лід / акцентний текст
--foam  #F2F8FE  текст          --mute #8FB4D6  другорядне     --mark  #EB5113  знак бренду (ЛИШЕ квадрат у лого)
```
Контраст: foam/night 17.2:1, ice/night 14.6:1, sky/night 8.9:1, mute/night 7.8:1, night/sky (кнопка) 8.9:1 — усі ≥ 4.5:1 [оцінка за формулою WCAG, без приладу].

Зв'язок із дизайн-системою «ПБТ-Спецтехніка» (артефакт, 22.09): принципи збережено — вердикти замість метрик, групування простором,
цифри в моно, помаранчевий лише як марка. Палітра навмисно інша: наказ власника «синьо-блакитний» + предмет (вода). Світла тема CRM лишається для CRM.

## Сцена героя (все — функція прогресу скролу, без таймерів)

`p ∈ [0,1]` на 320vh: кадри амфібії 0→0.72 (40 кадрів, декодований кадр підміняється лише коли готовий — без порожнього);
слово «ПБТ» зменшується й гасне 0.22→0.62; вода піднімається 0.5→0.985 і затоплює герой; текст гасне 0.76→0.96.
Каустика — canvas ≤25 к/с, лише `data-quality=full`, лише десктоп, лише поки герой у кадрі. `prefers-reduced-motion` → `static`: герой без сцени, усе видно одразу.

## Профіль пристрою

Як у ЛЮБЕ АВТО: `wide-fine / medium-hybrid / compact-touch` за можливостями (pointer, розмір, пропорції), не за назвою. На `compact-touch`
вікно з кадрами стає тлом на весь екран, аерознімок і каустика не вантажаться.
